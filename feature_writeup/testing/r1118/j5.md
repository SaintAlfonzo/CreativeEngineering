## Tool fixes

- `qrun.py` `install_probes` now goes through a new `probes_needed(rows)`. A probe is installed when (1) a `> root`
  command uses a root only it registers (as before, jar roots dropped), (2) a step or the row's `@commands` names its file
  (`NAME_probe.js` or `zz_NAME_probe.js`; mentions followed by "retired", "not used" or "no longer" are skipped), or (3)
  a log check (expect, reject, count, waitlog, boot*, kjs*) looks for a `[tag]` that only that probe prints (no other
  probe and no file in `development/` or `kubejs/` (exported and build excluded) prints it). Section `@@text` is left out
  because it holds run-log history: SALT's names 27 probes. An already-present `zz_` file (from a `@@prep copy`) is
  still skipped. The "copied" line drops "for /" when no root is involved. Dry run over every .qb section except MELT:
  rootless probes now picked up for CBB (nch_guard), CC (cc_dict, cc_phantom, cc_seqasm), CCO (cc_dict), SPFX
  (nch_empty_fluid) and WGE (zq_probe, named in SQ-WGE's `@commands`). Root-based sets are unchanged. py_compiled; the
  driver runs qrun per step, so the change applies from the next step.
- `qrowlint.py` and `qlint.py`: new lint warning `trail-space` for a check line (expect, reject, kjs*, boot*) that ends
  in a space. qrun strips the space, so the regex matches a longer id (cause of SQ-CM-02). 264 such lines exist in 34 .qb
  files (CBO's 30 `reject \[cbo\] leak ` and others). Warning only: I did not change qrun's parsing in the middle of a
  run, because some of these lines need the stripped form (`items=-` at the end of a log line).
  `tools/test_queue_rows.sh` 13/14; PROC-20 fails as before (render lag, CBB / MELT).
