# JEI coverage gaps

A catalog of what players can do in this pack that JEI never shows: recipes it can't draw, recipe
types with no JEI category, and world interactions (right-click, drop-in, mob drops by mechanic...)
that no recipe describes. Each gap gets a suggested fix so the list can be worked down.

- **Fix kinds used in the tables:**
  - **stand-in**: register ordinary shaped/shapeless display recipes in a JEI plugin, the way Supplementaries
    and Create do for their own special recipes. Needs Java (patcherMod's JEI plugin); KubeJS 1902's
    `JEIEvents` can't add recipes to a category.
  - **info**: a JEI information page on the item (`JEIEvents.information` in a client script). For
    recipes that don't fit a grid picture.
  - **none**: not worth fixing (explained in the row).

## 1. How JEI decides (crafting)

Read from the JEI 11.8.1.1034 jar (`VanillaRecipes`, `CategoryRecipeValidator`, `VanillaPlugin`):

- A recipe whose `isSpecial()` is false gets a page when its result is not empty and
  `getIngredients()` has 1 to 9 entries. Otherwise it's skipped (logged at debug level only).
- JEI's built-in crafting extension is registered for `CraftingRecipe` with the filter
  `!isSpecial()`. So an `isSpecial()` recipe gets a page only if:
  - a plugin registered a crafting extension for its class or a superclass, or
  - JEI or a plugin adds stand-in display recipes for it. JEI itself does this for exactly four vanilla
    classes: tipped arrow, shulker box colouring, suspicious stew, shield decoration.
- Which plugins do what was read from every mod jar's JEI plugin bytecode (`addCategoryExtension`
  calls, `addRecipes(RecipeTypes.CRAFTING, ...)` calls, recipe-manager plugins). The lists are
  `EXTENSIONS` and `STAND_INS` in the tool.

### Notes on part 1

- **Ours first:** `creativeengineering:elytra_duplication` is the only pack-made gap. A stand-in
  (elytra + dragon scale -> elytra x2) in patcherMod's JEI plugin is a few lines.
- **Botania** documents its hidden recipes in the Lexica Botania, so in-game help exists, just not in JEI.
- **CB Microblock** is a combinatorial saw recipe (every block x every cut). It doesn't fit stand-ins;
  an info page on the saws is the realistic fix.
- **Quark mixed_exclusion** recipes only exist to keep chests and furnaces craftable from mixed wood or
  stone when Quark's variant chests/furnaces are on. Players find them by accident; left as **none**.
- **Vanilla** special recipes are well known, but new players do look for firework and map recipes in
  JEI. Cheap stand-ins if wanted.
- Recipes for items in `global.removedItems` are hidden from JEI on purpose
  ([jeichanges.js](../kubejs/client_scripts/jeichanges.js)) and are not gaps.

## 3. Part 2: recipe types with no JEI category

Not started. Input is already exported: `kubejs/exported/recipes/recipe_types.json` (from the same
`/dumpcraftingaudit` run) lists every RecipeType with its recipe count, classes and serializers. The
plan: list every JEI category's RecipeType from the plugins (client side), diff against that file, and
for types that do have a category check whether the category drops some recipes (as JEI does for
crafting above). Known already: Vinery's types (fixed in patcherMod 1.0.3, see [vinery_jei.md](vinery_jei.md)).

## 4. Part 3: world interactions

Not started. Candidates to sweep: right-click block/item interactions (Vinery leaves and stems, sinks,
cauldron-style fills), in-world transformations (Botania-style drop-ins, lightning, fire/lava, Create
fan processing is already a category), mob-specific drops and shearing, and the pack's own KubeJS
event handlers (`BlockEvents.rightClicked`, `ItemEvents.rightClicked`, `EntityEvents.hurt`...).

## 7. History

- 2026-10-01: Part 1. Added `/dumpcraftingaudit` and `tools/jei_coverage.py`. Ran the dump on a scratch
  dedicated server (15,572 crafting recipes, 132 special). Read JEI 11.8's validator and the JEI plugins
  of every mod jar to build the coverage lists. Gotchas hit while writing the dump: Rhino here only sees
  Mojang method names (SRG names are "not a function"), `Recipe.getType()` is shadowed by KubeJS's
  `kjs$getType` (returns the serializer id), and `Ingredient.getItems()` is hidden behind IngredientKJS
  (use `getStacks()`).
- 2026-10-02: refreshed from the `/dumpall` export after the 1.0.4 mods (15,808 crafting recipes, 133 special,
  70 hidden). One new hidden recipe: Farmer's Respite kettle pouring (`farmersrespite:drink_pouring`, recipe id
  `minecraft:drink_pouring`); its JEI plugin only registers the Kettle brewing category. Described in the tool,
  fix kind stand-in.
