# Hand-placed loot: containers with fixed contents and no loot table

Generated by `python3 tools/loot_breakdown.py` on 2026-10-14. Back to the [index](README.md).

A structure builder filled these containers by hand, so nothing is rolled: **every item listed is always there** (count shown is the fixed stack size; slot positions are not shown). Lootr cannot give these containers per-player loot, because it only converts containers that have a loot table. To replace one with your own table you have to edit the template (or run `tools/lootr_fixed_containers.py`, which does it for the structures in `kubejs/data`).

Positions are block coordinates inside the template (x, y, z), enough to find the container in the structure block. "Structures" resolves each template to the structure(s) that can place it; village houses are one piece of a village.
