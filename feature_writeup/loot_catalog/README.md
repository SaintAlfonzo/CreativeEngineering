# Loot catalog: every container loot table and every hand-placed container

Generated by `python3 tools/loot_breakdown.py` on 2026-10-03 (re-run after mod updates or a fresh `/dumploot`). Read-only reference for building replacement loot tables; nothing here is applied by the game.

## What is in here

- [handplaced.md](handplaced.md): 963 containers filled by hand in structure templates (164 chest-like, 799 functional), plus 151 converted to `chests/fixed/*` tables. No loot table exists for these.
- [by_structure.md](by_structure.md): the same data turned around, one row per structure: which tables its containers roll, how many containers, whether the structure can spawn at all in this pack, and its hand-placed containers. Start here to work through structures one at a time.
- `tables/<namespace>.md`: 383 container loot tables in 47 namespaces (213 placed directly by a structure template, 93 pulled into other tables, 77 reached by code or loot modifiers). Block drops, mob drops and gameplay tables (fishing, gifts, bartering) are not containers and are not listed.

## How to read a table entry

- **Count** is the stack size an entry gives (`set_count`): `1-3` is uniform min-max, `+n` adds to an earlier count, `1` when there is no `set_count`.
- **Weight** and **Chance per roll** are the entry's weight and its share of the pool's total weight. Vanilla drops entries whose conditions fail from the draw, so conditional entries change the real shares; the percentage is nominal.
- **Rolls** are the number of draws per pool each time the container is opened (a range is uniform). A pool draws entries independently, with replacement, so the same entry can come up twice. `bonus_rolls` only matter with luck.
- **Sub-table** entries (`-> table x`) roll another table in place; the sub-table is listed in its own right (linked).
- **Tag** entries pick one member of the tag (or all, with `expand`).
- Entries marked *added in code by a mod* are not in the JSON: a mod appends them when the table loads (Quark, Buzzier Bees, Supplementaries, Sophisticated Backpacks...). Weights of those come from the `/dumploot` export and are approximate.
- Global loot modifiers (Armor Trims, Farmer's Delight, Everything Copper...) add items **after** the roll; they are listed above each table, not in it.

## What this does not show

- The pack's own pre-roll rules (`loot_config.json`, `07_rules.js`: PneumaticCraft and Lightman's coins banned, chalk x0.5, golden food x2, packed food) rewrite weights at load; tables here are the mods' originals. See [loot.md](../loot.md) section 3.8.
- Lootr: each player rolls their own copy at first open; the tables are the same.
- Containers whose table is chosen in code (vanilla mineshafts, strongholds, YUNG's data markers...) show their table under "Placed by" with the path where it was found.
