- **Files:** `structure_groups.json` (every rate: `groups.<name>` placement + structures{weight,frequency,enabled}; `standalone.<set id>` placement overrides + structures), `group/*` tags in `structure_tags.json` (membership; no multipliers anywhere now), `structure_config.json` = read-only scanner baseline (no current/enabled; has `meta_structures`).
- **Semantics:** group set `creativeengineering:group/<name>`; vanilla weighted pick with biome fall-through; then patcherMod rolls `frequency` (hash of seed, chunk, structure id) right before `setStartForStructure` (m_220516_) in `tryGenerateStructure` (m_223104_); a miss VETOES the rest of that set's picks in that chunk (no fall-through), so lowering one never boosts another. `StructureCheck#canCreateStructure` (m_226755_) uses the same roll for /locate. KubeJS stages the table via `StructureFrequencies.stage(json)` in highPriorityData; frozen at ServerAboutToStart, cleared at ServerStopped. No StructureFrequencies class (old jar) -> script applies NOTHING.
- Emptied original sets are written with `structures: []` + frequency 0 (codec allows empty; invisible to /locate). Standalone exclusion zones that pointed at emptied sets were retargeted to the group with a radius keeping the same excluded share.
- **Migration fit** (`tools/gen_structure_groups.py`): per-biome old density (biome pools from jar tags + kubejs/data + biome_merges, namespace-less tag ids default to minecraft, Beautify tags need loads_lenient; areas = biome_config result_pct), least squares on log density for weights + frequencies; grid sized for the most crowded biome (QUANTILE 1.0) so nothing is capped. Result x0.89..x1.13 for all 164 rated structures. Old files archived in `kubejs/archive/worldgen/pre_groups_2026-09-27/`.
- **Sync** (default mode): adds new members/groups/standalone sets, moved members keep the rate the file gives them now (doc_densities), stale entries removed; never edits existing values. `/cdevgen` worldgen group runs it after biome_config.
- Tests: `tools/test_structure_groups.sh` (node sim, Rhino byte parity, old-jar refusal, 13 Java checks with Bootstrap). `check_structure_live.py` section 4 now compares the live dump to the sim's files (flags 76 sets on a pre-groups dump, expected).
