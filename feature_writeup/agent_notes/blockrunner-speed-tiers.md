- **KubeJS ID tag filter skips unregistered ids silently** (TagEventFilter$ID checks getElementIds(); only throws with dev.properties strictTags=true, which is false here) — no ghost-entry risk like [axe-tag-ghost-entries](axe-tag-ghost-entries.md). `t.mirror(e, tags, rename)` in tag_helper uses `event.getElementIds().toArray()` (Rhino-harness tested) to add look-alike copies; blocktags uses it for SecurityCraft reinforced_<x> / <x>_mine.
- **Don't strip `_door` from all tiers:** framed/copycat doors are deliberately in camouflage; exclude doors in the specific pattern instead.
- **tag_helper.js / item_dict.js are startup scripts:** tier edits that use a new helper or dict key need a game restart, not just /reload.

- **Native friction/jump is NOT overridden by BlockRunner (only speedFactor).** Create D&D asphalt ships friction 0.35 / speedFactor 0.001 / jumpFactor 1.25, so it gave about 3.4× speed on top of the tier. Reset to friction 0.6 / speed 1.0 in `kubejs/startup_scripts/changes/block_properties.js` (BlockEvents.modification → `block.setFriction`/`setSpeedFactor`); jump is kept. Check new tiered blocks' Properties for friction/jump the same way (javap the registration lambda; `m_60911_` = friction, `m_60967_` = jumpFactor, `m_60956_` = speedFactor).

- **Deliberately untiered:** soul sand/soil (a tier's ADDITION modifier would stop Soul Speed cancelling the slowdown), carpets / 1-2 layer snow / pressure plates / IW leaf piles (BlockRunner reads getBlockStateOn = ~0.2 below feet, so the block beneath counts; leaf piles use makeStuckInBlock anyway), magma, functional blocks. Soul-sand-style sinking for soft/dust/spongy/very_sticky: see [sinking-blocks-investigation](sinking-blocks-investigation.md).
- **One tier per block:** BlockRunner resolves tag values with putIfAbsent over a HashSet, so a block in two tiers gets a random one per reload. Block-ID keys in the json always beat tags. A tiered block's native getBlockSpeedFactor is forced to 1 (IP asphalt 1.2, honey 0.4 replaced by the tier).
- **Wildcards:** `_glob()` turns `'minecraft:*_concrete'` into `'/^...$/'`; KubeJS TagEventFilter.RegEx matches with find() against every registry id on add, and on remove only strips direct id entries (not nested `#tag` refs). `*` never crosses ':'; no namespace = minecraft.
- **KubeJS pre-pass:** `getObjectIds()` on a PreTagEventJS returns [] and sets `invalid=true`; KubeJS then re-runs all block-tag scripts on the real load, which is what makes except/overlaps work. `_isPreTag()` only silences warnings.
- BlockRunner mixes into LivingEntity, so mobs and mounts get the speed too. HappyTrails was uninstalled 2026-09-26 (duplicate feature, permanent modifier, FOV warp).

- **Facing-aware sticky (patcherMod, deployed 2026-09-26):** `mixin/BlockRunnerBlockStateMixin` (was BlockRunnerStickyFacingMixin) injects at RETURN of BlockRunner's merged `blockrunner$tryAddBlockSpeed` (priority 1500 > BlockRunner's 1000, required to target another mixin's merged method; require=0). `surface/StickyFacing` removes BlockRunner's modifier (BlockSpeedManager.SPEED_MODIFIER_BLOCK_SPEED_UUID) when the on-block is in `#creativeengineering:blockrunner_face_up` (= #blockrunner:surface/sticky) and has `facing` != up or piston `type` != sticky.
