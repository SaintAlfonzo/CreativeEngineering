## Gotcha: solid blocks never see the sky (2026-11-21)

Serene Seasons' `underground_fertility_level` (32 in this pack) makes a position below it neutral when
`level.canSeeSky(pos)` is false. A solid block (grass block, any full-cube spreader) never sees the sky at its own
position, so a season check on the block itself is neutral below y 32, including every superflat scratch pad (y -61).
Read seasons for spreading blocks one block up (`CropSeasons.refuseSpread` does since plan_scratch_findings_1121 F2).
