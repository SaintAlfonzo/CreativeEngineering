# Creative Compat 1.0.0 (CurseForge file changelog)

First release.

- Compatibility fixes and tweaks for third-party mods. Each one switches on only when its mod is installed.
- Changes that need no other mod: melting ice and snow, no fire in the End, block walking speeds, walking through plants and layers, falling snow layers, two flower pots in one block, an iron golem farm cooldown, boat friction, TNT shrapnel and interface details.
- Low gravity for items, blocks, projectiles and boats (Create: Gravity) was part of Creative Common up to 1.2.0 and is now here. Edited settings that moved from Creative Common carry over.

The project page lists every change and its settings.

## Requirements

Minecraft 1.19.2, Forge 43 or newer, Creative Common 1.3.0 or newer (which requires KubeJS 1902.6.2-build.73 or newer, 1902.6.x). Both client and server need it.
