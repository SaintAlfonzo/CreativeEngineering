Static scan: loot tables set at placement time by code or processors (YUNG's, mineshaft minecarts...) are not visible here; Lootr converts those in game anyway.

Lootr converts natively: `minecraft:chest`, `minecraft:trapped_chest`, `minecraft:barrel`, `minecraft:*shulker_box`, `quark:*_chest`. Swaps: `loot_container_swaps.json`.
